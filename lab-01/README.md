# The Broken Light — практична робота 1

Невеликий вебзастосунок: заставка зі смугою завантаження й головне меню
гри «The Broken Light». Версія 1.0.0.

## Технології
HTML, CSS, JavaScript. Фреймворків і збирання не потрібно.

## Як запустити
1. Завантажте або клонуйте репозиторій.
2. Відкрийте теку `lab-01/`.
3. Відкрийте файл `index.html` у будь-якому сучасному браузері
   (Chrome, Edge, Firefox) подвійним клацанням.

Збирати нічого не потрібно.

## Як це працює
Після відкриття сторінки показується заставка зі смугою завантаження
(2,5 с). Потім вона затемнюється, і з'являється головне меню з
логотипом та пунктами «Почати», «Опції», «Вихід з гри». Пункти меню є
заглушками.

## Структура
- `index.html` — розмітка заставки й меню
- `style.css` — стилі
- `script.js` — перехід від заставки до меню
- `assets/logo.svg` — логотип (векторний)
- `assets/fonts/` — шрифт Cinzel (ліцензія SIL OFL)
